# Hub (Next.js)

Arabic RTL launcher for Balance Bites Ops. Run from this folder:

```bash
cd hub
npm install
npm run dev
```

Open http://localhost:3000

Copy `.env.example` to `.env.local` (never commit). Firestore rules are live. Vercel Root Directory must be `hub`.
